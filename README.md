# Lite TV Launcher

A lightweight Android TV home screen based on the existing BareLauncher source project. This port brings its wallpaper-first home screen, live clock/date, app shelf and TV-remote navigation into this repository.

## Included features

- Full-screen wallpaper background with clock and date.
- App shelf and app drawer operated with a TV remote.
- Reorder, hide, launch, inspect and uninstall apps.
- Wallpaper selection, slideshow folders and idle screen hiding.
- Remote-button shortcuts, TV input tiles, and backup/restore.
- No advertising or analytics added by this fork.

## Build

Open this repository in Android Studio, or run `bash ./gradlew :app:assembleDebug` from the repository root with Android SDK Platform 36 installed.
